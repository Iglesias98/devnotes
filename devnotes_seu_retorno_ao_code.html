Conceitos Web & JS Revisitados neste App

1. LocalStorage & Persistência de Dados

O `localStorage` permite guardar dados do tipo chave-valor no navegador do usuário. Convertemos nossos objetos em Strings utilizando JSON.stringify() e depois revertemos para código com JSON.parse().

2. Manipulação Avançada do DOM (Document Object Model)

Ao invés de recriar a página toda, selecionamos elementos usando document.getElementById() ou querySelector() e alteramos seu conteúdo dinamicamente via innerHTML ou classList.

3. Métodos Funcionais de Array (filter, map, sort)

Assim como os list comprehensions do Python (ex: [x for x in list if condition]), em JavaScript usamos métodos funcionais encadeados como .filter() para filtrar notas por busca/tag e .sort() para ordenação por data.

4. Blobs & Downloads (Exportação)

Para gerar arquivos JSON ou Markdown para download sem precisar de servidor/backend, usamos a API Blob nativa do browser e disparamos um clique sintético via link <a> virtual.
